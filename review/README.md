# Инвесторское ревью — Slice

Критический разбор проекта **Slice** глазами инвестора. Линза — **венчурный фонд
стадии seed / pre-seed**. Цель — заранее показать слабые места, red flags и
вопросы, которые задаст фонд, чтобы команда могла закрыть их до фандрейзинга.

> Ревью основано на питч-материалах (`pitch.md`, `slides.md`) и документации
> [../docs/tokenization/](../docs/tokenization/). Тон критический по запросу: ниже разобраны и сильные
> стороны, и риски. Это взгляд скептичного инвестора, а не приговор проекту.

## О проекте кратко

Slice — платформа токенизации реальных активов на Solana: актив оборачивается в
SPV-юрлицо и дробится на торгуемые фракции (Token-2022). Стадия — рабочий MVP /
proof-of-concept, сделанный за хакатон Decentrathon: 11 контрактов на Solana
devnet, фронтенд из 30 страниц, 160+ тестовых активов. Реальных пользователей,
выручки и токенизированных активов — нет. Команда — 4 человека из Казахстана.

## Инвестиционный вердикт

🟡 **Pass for now — revisit позже.**

Сильная инженерная команда и неожиданно зрелый для хакатона прототип. Но в
текущем виде проект **не investable**: отсутствует «the ask» (что именно
привлекают), не закрыт ключевой юридический риск, на котором держится весь
value proposition, нет стратегии выхода на рынок и нет ни одного реального
пользователя или пилота.

**Что хочется увидеть до следующей встречи:** (1) юридическое заключение о
работоспособности SPV-структуры в AIFC и о классе токена как ценной бумаги;
(2) первый реальный пилот или подписанный LOI; (3) внятный «the ask» с
финмоделью и use of funds; (4) усиление команды юридической / финансовой
компетенцией.

## Scorecard

| Критерий | Оценка | Кратко |
|----------|:------:|--------|
| Команда | 🟡 | Сильные инженеры; нет юр./фин./бизнес-компетенции и био |
| Рынок | 🟢 | Рынок реально огромный; источники по SAM корректны |
| Продукт / MVP | 🟢 | Рабочий end-to-end прототип — редкость для хакатона |
| Бизнес-модель | 🟡 | Понятна, но выручка тонкая; есть противоречие в цифрах |
| Юнит-экономика | 🔴 | Не раскрыта; расходы на SPV per-asset угрожают марже |
| Юридика / регуляторика | 🔴 | Главный нерешённый риск — весь value prop держится на нём |
| Трекшн | 🔴 | Только тестовые данные; 0 реальных пользователей, выручки, LOI |
| Defensibility | 🔴 | Open-source контракты форкаемы; «первый в РК» — не moat |

🟢 — сильная сторона · 🟡 — есть вопросы · 🔴 — серьёзный риск / пробел
