# Спринты — дополнения к презентации Slice

Папка с ресерчем и материалами для согласования с боардом по доработке
презентации Slice. Основано на инвесторском ревью ([../review/](../review/)) и
стратегическом обсуждении команды (разворот к модели RBF).

## Два трека

Каждый аспект прорабатывается для двух равноправных стратегических треков —
направление выбирает боард:

- **Track A — Универсальная токенизация активов.** Текущая модель: реальный
  актив оборачивается в SPV-юрлицо и дробится на торгуемые доли (Token-2022).
  Описание механизма токенизации — в [../docs/tokenization/](../docs/tokenization/).
- **Track B — RBF (Revenue-Based Financing).** Финансирование малого и среднего
  бизнеса обычными людьми через процент от будущей выручки: инвестор вкладывает
  сумму под множитель (напр. ×1.5), выплаты идут по мере поступления выручки,
  фиксированного срока нет.

## Как устроен каждый спринт

Один файл, две секции:

1. **Ресерч** — findings с обязательными ссылками `[n]`. В каждом ресерче два
   отдельных среза: **глобальный** и **Казахстан**.
2. **Board-memo** — 2–3 подхода с плюсами/минусами и рекомендацией; в конце блок
   «Что должен решить боард». Шаблон — [templates/board-memo.md](templates/board-memo.md).

## Источники

Все ссылки собраны в [sources.md](sources.md) со сквозной нумерацией `[n]`.
Приоритет источников — международные экономические форумы и институты (WEF,
World Bank, IMF, OECD, ADB, BIS, IOSCO), первичное законодательство, официальная
статистика. Каждая цифра в спринтах сопровождается ссылкой.
