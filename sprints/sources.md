# Источники

Сводная библиография для спринтов. Сквозная нумерация `[n]`; в текстах спринтов —
инлайн `[n]`. Сгруппировано по спринтам; источники, использованные в нескольких
спринтах, не дублируются — указаны по месту первого появления.

Приоритет — международные экономические форумы и институты, первичное
законодательство, официальная статистика. Часть PDF (IFC, ADB, WEF, BIS)
недоступна прямой загрузкой — данные брались из поисковой выдачи и
кросс-проверялись; такие случаи помечены в секциях «Ограничения ресерча» спринтов.
